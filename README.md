# ❄️ NixOS - my desktop modular configuration

Modular NixOS and Home Manager configuration repository, using Flakes for reproducibility.

## 📂 System Module Structure

A modular option-based architecture (`lib.mkEnableOption`), allowing to toggle between components.

```text

├── flake.nix                        # Entry point and dependency management
├── desktop/
│   ├── configuration.nix            # Main machine configuration (module activation)
│   └── hardware-configuration.nix   # Generated by NixOS (filesystems, partitions)
└── modules/
    ├── system/                # System-level modules (NixOS)
    │   ├── gnome.nix          # GNOME configuration
    │   ├── hyprland.nix       # Hyprland (Wayland window manager) configuration
    │   ├── nvidia.nix         # Nvidia drivers
    │   └── pipewire.nix       # udio server
    └── user/                  # User-level modules (Home Manager)
        ├── bash.nix           # Shell and aliases
        ├── development.nix    # Programming tools (Rust, Go, Podman, etc.)
        └── git.nix            # Version control and credentials

```

## 🛠️ How to Use

### Testing changes (without saving to bootloader)

```bash
sudo nixos-rebuild test --flake .#nixos

```

### Applying and saving to bootloader

```bash
sudo nixos-rebuild switch --flake .#nixos

```

### Updating the system (Flake inputs)

```bash
nix flake update
sudo nixos-rebuild switch --flake .#nixos

```
